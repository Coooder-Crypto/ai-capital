当前 MVP 数据

页面内置的是人工整理的 seed 数据，用来验证产品交互、关系结构和证据展示。 正式接入后，指标会由 worker 定时从公开 API 更新。

  • 上市公司财务：SEC EDGAR company facts、10-K、10-Q。
  • 开源热度：GitHub REST API。
  • 模型生态：Hugging Face Hub API。
  • 论文影响力：OpenAlex / arXiv。
  • 关系证据：公司公告、财报、案例页、公开新闻与人工审核。

估值展示规则

上市公司展示市值或企业价值；私营公司只展示公开披露的最近估值。 没有可靠来源时显示 Unknown。所有指标都需要保留来源、日期和置信度。

  • Market cap：公开行情和股本数据计算。
  • Reported valuation：公司、投资人或可信媒体披露。
  • Estimated valuation：必须明确标注为估算。
